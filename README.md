# FUJAX SOH Report — Invoicing

Interactive Connect Logistics report for reconciling FUJAX transport invoices to the 2026 master stock report.

## Current study population

- 7 invoices received
- 343 invoiced loads
- 12,126.00 billable tonnes
- R7,475,985.01 invoiced ex VAT
- 343 exact master matches

## What the report provides

- Invoice-level billed tonnage, rate and totals
- Load-by-load invoice number and linked rate per ton
- Search and filtering by invoice, order, ticket and status
- Source-versus-master load detail
- CSV export and browser print/PDF output
- Reconciliation controls and source position

The current report confirms invoice arithmetic and master linkage. Charged rates are displayed but have not yet been compared with an approved tariff schedule.

The live site is deployed automatically from `main` using GitHub Pages.
